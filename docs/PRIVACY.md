# 数据、权限与凭证

本插件是社区开发的 DeepSeek Harness 模型 Provider，不隶属于 OpenAI 或 DeepSeek。使用者自行在 OpenAI 页面登录并审核授权。插件不读取其他程序的登录凭证。

## 发送的数据

授权、刷新及撤销请求发送至 `https://auth.openai.com`；账户模型目录和推理请求发送至 `https://api.openai.com`。推理请求包含当前会话所需的文本、工具定义、工具结果和所选图片。DSH 宿主决定哪些历史和工具结果进入请求。图片经宿主附件服务读取，不额外上传到图床。

请求设置 `store:false`。这不是对上游零保留的承诺；上游处理及保留规则见 [OpenAI 隐私政策](https://openai.com/policies/privacy-policy/)。插件没有独立遥测服务、广告 SDK 或付费 API 自动回退。

## 本地存储与权限

OAuth 凭证保存在本插件独立目录，默认 `~/.dsh/plugin-data/dsh-codex-official-adapter/auth`。目录权限 0700，文件权限 0600；文件未加密，不是系统钥匙串。账户身份用于设置页显示。凭证、授权码和完整请求不应记录到日志或公开报告。

插件使用宿主的模型、认证连接、图片附件和可选默认模型服务。宿主执行文件、终端等工具；本插件将调用和结果适配为模型协议，并不因此授予工具额外权限。开启“新会话默认使用 GPT”会修改宿主默认模型偏好，可在设置页关闭。

## 断开与卸载

先在“设置 → ChatGPT 订阅”退出账户：插件尝试撤销远程刷新会话并清理本地凭证。如果远程撤销未确认，到 ChatGPT 设置中断开该应用。卸载插件不会自动等同于远程撤销，宿主会话也不会因此删除。通过桌面插件管理器卸载，或执行 `dsh plugin --profile desktop remove dsh-codex-official-adapter`。

报告问题时请删除邮箱、会话正文、授权链接和凭证。
