# 调节思考强度

1. 在会话输入框右下角选择一个 **ChatGPT plan** 模型。
2. 再次点击模型按钮，打开 **推理等级**。
3. 选择所需档位，下一次回复即使用该强度。

| 档位 | 适合的任务 |
| --- | --- |
| 低 | 简单问答、快速修改 |
| 中 | 日常开发与分析 |
| 高 | 复杂问题、代码审查 |
| 很高 | 更深入的推理与排查 |
| 最大 | 难度较高、可接受较长等待的任务 |

可选档位和默认值以当前账户、当前模型为准；部分模型也支持“不思考”或“最少”。插件只展示模型目录和 Responses 接口共同支持的档位。更高强度可能增加等待时间和订阅消耗，不保证每个任务的回答更好。

切换模型后请重新确认档位。无需安装额外插件或手写配置。
