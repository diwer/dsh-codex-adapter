FROM SIGN-IN TO YOUR FIRST IDEA

Three steps. You’re in.

Harness desktop 0.2.0-rc.2 on macOS · An eligible ChatGPT account is required.

  1. 01

    Install the plugin

    Open Plugins → Add plugin. Paste the package below and select the official npm registry. Click Install, then fully quit and reopen Harness after current tasks finish.

    dsh-codex-official-adapter@0.1.6

    Official npm registry ↗
  2. 02

    Connect your account

    Open Settings → ChatGPT 订阅 → 连接 ChatGPT. Follow the link to OpenAI, sign in, and authorize your account. Models load automatically when you return.

    Harness⇄ChatGPT
  3. 03

    Start creating

    Start a new conversation. Choose a model under “ChatGPT plan (Sign in with ChatGPT)”, then ask a question, attach an image, or work on your project.

A FEW THINGS TO KNOW

Good questions.
Clear answers.

Which product does this plugin support? DeepSeek Harness only. It cannot be installed in the regular DeepSeek chat website, mobile app, or regular chat desktop client. The currently validated host is Harness desktop 0.2.0-rc.2 on macOS.

How do I use my ChatGPT subscription in DeepSeek Harness? Install dsh-codex-official-adapter@0.1.6, connect your own ChatGPT account in settings, and choose a model under ChatGPT plan. No API key is required. Your account determines model access and usage limits.

Can I install from GitHub? The source is at https://github.com/diwer/dsh-codex-adapter. Installer support varies across hosts and marketplaces; prefer the exact package name and version above.

No models after sign-in? Click 刷新模型. Check account permissions, usage limits, and network access. Available models come from your account.

Upgrading? Install the newer version using the same package name and restart Harness. Keep your existing Profile and account directory.

Uninstalling? Sign out in plugin settings, then uninstall in Plugins. See privacy and account removal.
