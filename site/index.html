在 Harness 桌面版使用 ChatGPT 订阅模型

在 DeepSeek Harness 桌面版 0.2.0-rc.2 使用 ChatGPT 订阅模型，支持 DeepSeek/GPT 切换、图片输入及宿主工具调用。开源 MIT 社区插件。

下载安装包 v0.1.1发行说明与校验文件GitHub 源码AI 可读文档

兼容与能力

  • 目标宿主：DeepSeek Harness 桌面版 0.2.0-rc.2；macOS 已做安装及运行时验证。
  • 独立 ChatGPT 账户授权，默认等待 30 分钟；模型目录以账户实际返回为准。
  • DeepSeek/GPT 切换，支持图片能力模型和宿主文件、搜索、终端等工具协议。
  • 插件本身免费开源；用户的订阅资格、额度和模型可用性另行决定。

本插件不是 OpenAI 或 DeepSeek 官方认证产品，不提供共享账号或 API Key 自动回退。

安装与升级

下载 dsh-codex-official-adapter-0.1.1.tgz，不要解压。在 Harness 桌面插件管理器中添加本地包。等待任务结束，完全退出并重新打开 Harness，然后进入“设置 → ChatGPT 订阅”授权自己的账户。

常见问题

这是什么插件？
为 DeepSeek Harness 桌面版增加 ChatGPT 订阅模型 Provider 的社区开源插件；不是 OpenAI 或 DeepSeek 官方认证产品。
DeepSeek 和 GPT 可以切换吗？
两种 Provider 保持并存；可以在会话模型选择器切换，新会话默认 GPT 的设置可以关闭。
支持图片和文件编辑吗？
支持目录中声明图片能力的模型；图片经 Harness 附件服务读取。文件编辑、搜索和终端等工具由宿主执行，本插件适配工具协议。
需要 API Key 吗？
本路由使用独立的 Sign in with ChatGPT 授权，不自动回退到付费 API Key；需要本人拥有可用账户及相应订阅权限。
安装后需要重启吗？
需要等待当前任务结束，完全退出并重新打开 Harness，再在设置中连接账户。
市场一定可以搜索到吗？
不能保证。不同市场的数据源、审核、同步周期和兼容过滤各自独立，市场覆盖文档记录实际进度。
远程 URL 安装提示缺少 integrity 怎么办？
部分宿主仍会复现此问题。请使用仓库 scripts/install-release.mjs：先校验固定 SHA-256，再由官方 CLI 安装本地包。不要删除整个锁文件或关闭完整性检查，详见校验安装文档。

数据与安全

会话所需文本、图片和工具结果发送到 OpenAI。凭证保存在本插件独立的明文文件内，目录权限 0700、文件权限 0600，不读取其他客户端凭据。阅读数据与隐私说明。
