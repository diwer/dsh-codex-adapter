从连接账户，到第一个想法

三步，开始创造。

适用于 Harness 桌面版 0.2.0-rc.2 / macOS，需要可使用订阅模型的 ChatGPT 账户。

  1. 01

    安装插件

    打开 Plugins → Add plugin，粘贴下方包名并选择 npm 官方源，点击 Install。等当前任务结束后，完全退出并重新打开 Harness。

    dsh-codex-official-adapter@0.1.5

    npm 官方源 ↗
  2. 02

    连接账户

    打开 Settings → ChatGPT 订阅 → 连接 ChatGPT，在 OpenAI 页面完成登录与授权。返回后，连接状态与可用模型会自动更新。

    Harness⇄ChatGPT
  3. 03

    开始使用

    新建会话，在「ChatGPT plan (Sign in with ChatGPT)」下选择模型。提出问题、添加图片，或直接开始处理你的项目。

开始之前，你可能想知道

常见问题，
清楚解答。

这个插件支持哪个产品？ 仅支持 DeepSeek Harness。DeepSeek 普通网页版、手机 App 和普通聊天桌面客户端不支持安装本插件。当前验证范围为 Harness 桌面版 0.2.0-rc.2 / macOS。

如何在 DeepSeek Harness 中使用 ChatGPT 订阅？ 安装 dsh-codex-official-adapter@0.1.5，在设置中连接自己的 ChatGPT 账户，再从 ChatGPT plan 中选择模型。无需 API Key，模型权限与额度由账户决定。

可以直接填 GitHub 地址吗？ 这是源码地址：https://github.com/diwer/dsh-codex-adapter。不同宿主与市场的安装器支持有差异，日常安装建议使用上面的明确包名与版本。

已经连接，却没有模型？ 点击“刷新模型”，检查当前账户的订阅权限、额度及网络。模型列表以账户实际返回为准。

如何升级？ 用相同包名安装新版本，然后完全退出并重开 Harness。保留原 Profile 和账户目录即可延续使用。

如何退出或卸载？ 先在设置页退出账户，再到 Plugins 卸载。详细说明。
